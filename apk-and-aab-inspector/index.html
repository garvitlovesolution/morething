About the APK and AAB Inspector

Upload an APK, AAB or ZIP file to see what is inside: the type, size, number of files, DEX code files, native CPU folders and the biggest folders. Use it to find what makes your app large. The file is read in your browser and never uploaded.

How to use it

Choose an APK, AAB or ZIP file and press Inspect file. You see the type, size and biggest folders.

Common questions

Can it tell me why my app is large?

Yes. The folder list shows what takes the most space, and the native ABI list shows if you ship code for many CPU types.

Are my files or text uploaded?

No. This tool runs in your browser, so what you enter is not sent to our servers.

Is it free?

Yes. It is free to use with no sign-up.
