About the JSON Formatter

Paste JSON to make it easy to read, or squeeze it into one line. Errors are shown if the JSON is not valid.

How to use it

Paste JSON and choose Format to make it readable, or Minify to shrink it to one line. Errors show if the JSON is invalid.

Common questions

Why does my JSON show an error?

The usual causes are a missing comma, single quotes instead of double quotes, or a comma after the last item.

Are my files or text uploaded?

No. This tool runs in your browser, so what you enter is not sent to our servers.

Is it free?

Yes. It is free to use with no sign-up.
