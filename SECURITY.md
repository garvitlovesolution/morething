# Security Policy

If you find a security problem in MoreThing, please do not open a public issue. Email velvetloom2@gmail.com with the details and steps to reproduce it. We aim to reply within 7 days and to fix confirmed problems quickly. Thank you for reporting responsibly.

Scope notes: the website runs in the browser and stores user data locally. The optional Worker in `worker/` stores only a push address and timestamps.
