About the QR Code Generator

Paste a website link or any text and get a QR code instantly. Download it as a PNG and print it or share it. The code is made in your browser.

How to use it

Paste a web link or any text. The QR code appears right away. Click Download PNG to save it, then print it or put it on a post.

Common questions

Do QR codes expire?

These codes hold your text directly, so they never expire. They only stop working if the link inside them stops working.

Are my files or text uploaded?

No. This tool runs in your browser, so what you enter is not sent to our servers.

Is it free?

Yes. It is free to use with no sign-up.
