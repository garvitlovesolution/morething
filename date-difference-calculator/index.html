About the Date Difference Calculator

Pick two dates to count the days, weeks and approximate months between them.

How to use it

Pick a start and end date. The tool shows the number of days, weeks and approximate months between them.

Common questions

Is the end date included?

The count is the gap between the dates. Add one day if you want to count both the first and last day.

Are my files or text uploaded?

No. This tool runs in your browser, so what you enter is not sent to our servers.

Is it free?

Yes. It is free to use with no sign-up.
