About the File Checksum Generator

Pick any file, such as an APK you are about to share, and get its SHA-1, SHA-256 and SHA-512 checksums. Compare them with the values a developer publishes to be sure the file was not changed or damaged.

How to use it

Choose a file and press Generate checksums. Copy the value you need.

Common questions

What is a checksum for?

It is a fingerprint of a file. If two copies give the same value, they are identical.

Are my files or text uploaded?

No. This tool runs in your browser, so what you enter is not sent to our servers.

Is it free?

Yes. It is free to use with no sign-up.
