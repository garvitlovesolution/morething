About the Increase File Size

Some forms ask for a minimum file size. This tool adds harmless empty data to the end of your JPG, PNG or PDF until it reaches the size you enter. The picture or document looks the same and still opens normally.

How to use it

Choose a JPG, PNG or PDF, enter a larger size in KB and press Increase size. Download the new file.

Common questions

Does this change my picture or document?

No. It adds empty data at the end of the file, so it looks the same and opens normally. Some very strict upload systems may still reject it.

Are my files or text uploaded?

No. This tool runs in your browser, so what you enter is not sent to our servers.

Is it free?

Yes. It is free to use with no sign-up.
