# Contributing to MoreThing

Thank you for helping.

- **Report a bug:** open an issue with the page, your browser, the steps to reproduce it, what you expected and what happened.
- **Suggest a tool:** open an issue describing the task people need to do. Tools that run fully in the browser and keep data private are the best fit.
- **Send a change:** fork the repository, make a small focused change, test it in a browser and open a pull request that explains why.

Guidelines:
- Keep tools private: no uploads of user files or text to a server.
- Keep pages fast and accessible (keyboard use, readable contrast, works on phones).
- Every tool page needs a short explanation, "How to use it" text and an FAQ.

Everyone must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
