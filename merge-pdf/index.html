About the Merge PDF

Select two or more PDF files and join them into one document, in the order you chose them. Files are processed in your browser and are never uploaded.

How to use it

Choose two or more PDF files in the order you want them, then click Create PDF and download the merged file.

Common questions

Is there a page limit?

There is no set limit. Very large files depend on your device memory, so merge in smaller groups if the browser slows down.

Are my files or text uploaded?

No. This tool runs in your browser, so what you enter is not sent to our servers.

Is it free?

Yes. It is free to use with no sign-up.
